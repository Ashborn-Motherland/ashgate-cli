# Security Policy

## Supported Versions

We release security updates for the latest major version of Ashgate CLI.

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

Security is paramount for payment tooling. If you discover a security vulnerability within Ashgate CLI, please do **NOT** open a public GitHub issue.

Instead, please send an email directly to security@ashgateway.com or contact the core maintainers.

We will acknowledge receipt of your vulnerability report within 24 hours and provide a timeline for a patch and advisory release.
